# ShopLite

ShopLite là một trang thương mại điện tử mini, được xây dựng dần qua từng phiên bản để luyện tập front-end.

## Cấu trúc

- `v1-html/` — Phiên bản 1: HTML semantic + CSS thuần (chưa có JavaScript).
  - `index.html` — Trang danh sách sản phẩm.
  - `style.css` — Reset cơ bản, web font và style nền tảng.

## Chạy thử

Mở `v1-html/index.html` trực tiếp trong trình duyệt.
